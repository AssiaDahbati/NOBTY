## ✨ What is NOBTY?

**NOBTY** transforms the traditional booking experience into a modern digital platform where users can discover businesses, explore services, and book appointments through a premium SaaS-style interface.

Designed with **scalability**, **responsiveness**, and **clean UI/UX** in mind — the platform delivers a smooth experience across both desktop and mobile.

---

## 🚀 Features

| Feature | Description |
|---------|-------------|
| 🔍 **Business Discovery** | Browse and find local or online service providers |
| 📅 **Appointment Booking** | Seamless, real-time booking flow |
| ⭐ **Ratings & Reviews** | Community-driven trust through feedback |
| 📱 **Responsive UI** | Pixel-perfect experience on any screen size |
| 🛠️ **Service Management** | Full control for businesses over their offerings |
| 🔐 **JWT Authentication** | Secure, stateless auth with JSON Web Tokens |
| ☁️ **MongoDB Atlas** | Cloud-native database integration |

## ⚡ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/NOBTY.git
cd NOBTY
```

### 2. Start the Frontend

```bash
cd frontend
npm install
npm run dev
```

> 🌐 Runs at `http://localhost:5173`

### 3. Start the Backend

```bash
cd nobty-backend
npm install
npm run dev
```

> 🔌 Runs at `http://localhost:5000`
